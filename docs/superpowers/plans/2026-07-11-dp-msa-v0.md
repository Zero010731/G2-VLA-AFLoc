# DP-MSA-v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement DP-MSA-v0 as a small disease-phrase-conditioned residual heatmap adapter over frozen AFLoc outputs.

**Architecture:** DP-MSA-v0 does not change AFLoc encoders and does not require deep AFLoc feature caches. It consumes a baseline heatmap, Chest ImaGenome-style region maps/scores, disease ids, and frozen phrase subtype ids, then produces `final_hmap = normalize(base_hmap + lambda * residual_map)`.

**Tech Stack:** Python 3.9-compatible syntax, PyTorch, NumPy, pandas, pytest, existing AnaPrior Stage C prepared inputs and score tables.

## Global Constraints

- AFLoc image and text encoders remain frozen.
- MS-CXR boxes, masks, and oracle profiles are not used for DP-MSA training or model selection.
- First implementation is DP-MSA-v0: no deep AFLoc spatial feature extraction.
- Raw learned, DCEM-v3 phrase-anatomy, shuffled, and baseline controls remain untouched.
- All production code is added after failing tests.
