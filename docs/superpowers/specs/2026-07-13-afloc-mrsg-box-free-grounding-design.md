# AFLoc-MRSG: Box-Free Morphology-Routed Sparse Grounding

> Status: implemented and rejected as the `absolute-decoder MRSG` ablation.
> Held-out MS-CXR evaluation showed severe all-class localization degradation.
> Preserve this document as the historical design. It is not the approved next
> architecture. See `docs/ANAPRIOR_RESEARCH_CONTEXT_2026-07-19.md` for the
> current diagnosis and Anchor-Preserving MRSG decision.

## Status

Historical approved architecture for the completed standalone experiment. The
experiment did not replace DCEM-v3 after held-out evaluation; it now remains an
ablation alongside the lightweight Dense DP-MSA adapter.

## Objective

Build a standalone disease-phrase localization model on frozen AFLoc image and text backbones. The model must learn spatial grounding from image-report pairs without bounding boxes, segmentation masks, anatomy regions, region predictors, oracle maps, or external weights trained with spatial annotations.

The model must address the observed pathology-dependent failures through shared spatial operators selected from phrase semantics and disease descriptions, rather than handwritten disease branches.

## Scientific Claim

AFLoc-MRSG learns pathology localization from report-level supervision by combining:

1. multi-scale phrase-token sparse grounding;
2. morphology-routed spatial query operators;
3. a box-free dual-consistency teacher.

The intended paper claim is annotation-free or box-free disease localization, not fully unsupervised learning. Image-report pairs provide semantic supervision.

## Hard Constraints

- Freeze the complete AFLoc image and text backbones.
- Do not train on MS-CXR boxes, masks, oracle maps, metric deltas, or oracle-derived properties.
- Do not use Chest ImaGenome boxes, region maps, scene-graph locations, or a region predictor trained from them.
- Do not load AGPT, MedRPG, CLIPSeg, DenseCLIP, or other weights trained with boxes or masks.
- Do not use DCEM-v3 heatmaps as input, pseudo-label, teacher, fallback, gate, or fusion source.
- Do not route by disease ID or disease-name conditionals.
- Exclude every MS-CXR patient and DICOM from MIMIC-CXR training and model selection.
- Fix all training losses and selection rules before MS-CXR test evaluation.

## Paper-Grounded Mechanisms

AFLoc-MRSG reimplements mechanisms over AFLoc features; it does not load the papers' pretrained spatial models.

| Source | Adopted mechanism | AFLoc-MRSG translation |
|---|---|---|
| [Locality Alignment](https://arxiv.org/abs/2410.11087) | Masked semantic reconstruction for patch locality | Train a pyramid neck to reconstruct frozen AFLoc patch embeddings from masked multi-scale context |
| [COSMOS](https://arxiv.org/abs/2412.01814) | Cross-modality self-distillation over local/global views | Use weak/strong image views and phrase views with an EMA teacher |
| [RadJEPA](https://arxiv.org/abs/2601.15891) | Masked latent prediction without language labels | Preserve conditional structure in the AFLoc patch pyramid |
| [GLINT](https://arxiv.org/abs/2606.03180) | Sparse query-specific patch gates | Learn independent sigmoid gates for phrase-conditioned spatial queries |
| [Zero-Shot Medical Phrase Grounding](https://arxiv.org/abs/2404.12920) | Aggregate cross-attention evidence across layers | Aggregate query-token evidence across scales rather than relying on one attention map |

Excluded mechanisms include box regression, GIoU loss, mask-token supervision, anatomy-box pretraining, and spatially supervised foundation-model proposals.

## Inputs

For each MIMIC-CXR image-report training row:

- `image`: frontal CXR and two geometry-tracked augmentations;
- `phrase`: a positive finding sentence mined from the paired report;
- `negative_phrases`: disease, location, and laterality counterfactuals validated against the report;
- frozen AFLoc image outputs:
  - `img_emb_l2`: high-resolution local representation;
  - `img_emb_l`: middle-resolution disease representation;
  - `img_emb_lf`: deep contextual representation;
- frozen AFLoc text outputs:
  - word embeddings;
  - sentence embedding;
  - report embedding;
  - attention mask;
- frozen disease-description embedding generated by the AFLoc text encoder.

No category ID is required by the model forward pass.

## Outputs

The standalone model returns:

- `final_heatmap [B,1,H,W]`;
- `query_heatmaps [B,4,H,W]`;
- `query_route_weights [B,4]`;
- `query_reliability [B,4]`;
- `phrase_patch_logits [B,T,H,W]`;
- `teacher_confidence [B,1,H,W]` during training;
- diagnostic attention and anti-collapse statistics.

`final_heatmap` is the model output. It is not added to an AFLoc or DCEM heatmap.

## Architecture

```text
Frozen AFLoc multi-level image features
             +
Frozen AFLoc word/sentence/disease-description features
             |
             v
Locality-Aligned Feature Pyramid
             |
             v
Phrase Token Projector + Semantic Router
             |
             v
Morphology-Routed Sparse Grounding Transformer
  |          |          |          |
focal      diffuse   boundary   structural
  |          |          |          |
  +----------+----------+----------+
             |
             v
Standalone Multi-Query Dense Decoder
             |
             v
final_heatmap
```

## Component 1: Locality-Aligned Feature Pyramid

### Purpose

Recover spatial detail discarded by a single AFLoc layer while preserving the frozen backbone's medical semantics.

### Forward

1. Project `img_emb_l2`, `img_emb_l`, and `img_emb_lf` to a shared width `D`.
2. Resize them to a common high-resolution patch grid.
3. Fuse with gated lateral connections and a two-layer transformer neck.
4. Add normalized image-gradient and local-contrast channels computed directly from the CXR.

The raw-image operators are deterministic and annotation-free. They provide boundary evidence without anatomy masks.

### Masked Prediction

Mask contiguous patch blocks in the trainable pyramid input. Predict the corresponding stop-gradient frozen AFLoc embeddings at each source scale. This prevents the neck from collapsing into a report-level classifier.

## Component 2: Phrase Token Projector and Semantic Router

### Phrase Representation

The model consumes all valid AFLoc word tokens and the sentence embedding. It never replaces the phrase with a subtype ID.

### Disease Description

Each finding has a frozen natural-language clinical description encoded by AFLoc. Descriptions may state visual morphology but may not contain MS-CXR-derived locations or oracle statistics. New findings can be added by supplying text, without changing model code.

### Router

The router cross-attends the sentence and disease-description embeddings to word tokens and predicts four mixture weights. A temperature-controlled softmax is used during training; no hard branch is selected.

Router supervision is indirect through grounding and consistency losses. Load-balancing prevents permanent single-query collapse.

## Component 3: Four Spatial Query Operators

The four operators share projected image and text tokens but implement different spatial inductive biases.

### Focal-Set Query

- Uses `K` learnable lesion slots.
- Applies deformable sparse attention to high- and middle-resolution patches.
- Produces `K` component maps merged by noisy-OR.
- Supports one or several compact abnormalities without a predefined component count.

Primary expected use: focal/multifocal pneumonia, consolidation, opacity, and focal atelectasis.

### Diffuse Query

- Uses window attention followed by global token exchange.
- Includes low-pass contextual features and bilateral relation tokens.
- Does not receive compactness or low-area pressure.
- Models broad texture changes and distributed evidence.

Primary expected use: edema and diffuse/bilateral pulmonary findings.

### Boundary Query

- Operates at the highest patch resolution.
- Cross-attends image-gradient, Laplacian, local-contrast, and semantic patch tokens.
- Uses contour continuity attention between neighboring patches.
- Suppresses isolated image-frame and text-marker edges through augmentation inconsistency and report negatives.

Primary expected use: pneumothorax and pleural-boundary manifestations.

### Structural Query

- Builds paired left/right spatial tokens around the image midline.
- Uses symmetry-difference attention and a global shape token.
- Models enlargement, displacement, and volume-loss patterns rather than local texture alone.

Primary expected use: cardiomegaly and structural atelectasis.

These expected uses are scientific hypotheses for analysis. They are not encoded as disease routing rules.

## Component 4: Sparse Grounding Transformer

Each query operator performs bidirectional alignment:

```text
text-to-image: phrase tokens select supporting patches
image-to-text: selected patches reconstruct supporting phrase tokens
```

Patch selection uses independent sigmoid gates rather than a spatial softmax. Gates are normalized only when aggregating evidence, so multiple or diffuse regions remain possible.

The transformer emits token-level logits and one map per query. Route weights combine the four maps only after each operator has produced spatial evidence.

## Component 5: Standalone Dense Decoder

The decoder receives the four query maps, fused pyramid features, route weights, and query reliability. It uses two refinement blocks and predicts an unconstrained heatmap logit map:

```text
final_heatmap = sigmoid(decoder(features, query_maps, route_weights, reliability))
```

There is no residual scaling, lambda sweep, DCEM fusion, or validation gate in the main method.

## Box-Free Dual-Consistency Teacher

### Teacher

Maintain an exponential-moving-average copy of the trainable neck, router, query transformer, and decoder. AFLoc remains the same frozen backbone for teacher and student.

### Views

- Teacher receives a weak photometric view.
- Student receives a strong photometric and geometry-tracked view.
- A second student pass uses masked patches.
- Horizontal flips swap left/right terms in the phrase; ambiguous bilateral phrases are unchanged.

### Confidence

Teacher confidence is deterministic, not a freely learned fallback head. A patch is confident when it satisfies:

- agreement across AFLoc scales;
- agreement across weak augmentations;
- stable query routing;
- positive phrase margin over hard negatives.

Low-confidence patches do not contribute to teacher consistency. Confidence never selects DCEM output.

## Training Data Protocol

1. Build a list of every MS-CXR patient, study, DICOM, and image path.
2. Remove all matching records from MIMIC-CXR before phrase mining.
3. Split remaining patients into train and validation with one frozen seed.
4. Mine positive finding sentences only from their paired reports.
5. Use validation losses and annotation-free diagnostics for checkpoint selection.
6. Run MS-CXR once after the architecture, checkpoint, and heatmap extraction protocol are frozen.

MS-CXR text may be supplied only as an inference query during final evaluation.

## Phrase Mining and Hard Negatives

Phrase mining uses report sentence boundaries and a frozen clinical lexicon. It extracts finding mentions, laterality words, location words, severity, and uncertainty. These are textual attributes, not spatial labels.

Hard negatives:

- replace the finding with a report-absent finding;
- swap left/right only when the report does not support both sides;
- replace a location only when the counterfactual is contradicted or absent;
- use another patient's phrase with a matched disease frequency;
- preserve negation and uncertainty semantics.

Every generated counterfactual is checked against the full report to avoid false negatives.

## Four Loss Groups

### 1. Cross-Modal Grounding Loss

```text
L_ground = L_phrase_image_MIL
         + L_patch_token_cycle
         + L_counterfactual_margin
```

- Positive phrase-image pairs require at least a stable top-k patch set.
- Token reconstruction must use selected visual patches with stop-gradient text targets.
- Counterfactual phrases must score below the positive phrase by a fixed margin.
- Cross-image negatives prevent language-only reconstruction.

### 2. Teacher Equivariance Loss

```text
L_teacher = confidence * distance(
    student_heatmap(strong_view),
    transform(teacher_heatmap(weak_view))
)
```

The loss applies to final and query-specific maps. Constant-map collapse is prevented by positive-negative margins and output-variance requirements.

### 3. Masked Patch Distillation Loss

```text
L_mask = sum_scale distance(
    predicted_masked_embedding,
    stopgrad(frozen_AFLoc_embedding)
)
```

The target is an AFLoc latent feature, not a spatial annotation or AFLoc heatmap.

### 4. Query Regularization Loss

```text
L_query = L_route_balance
        + L_query_diversity
        + L_noncollapse_variance
        + L_operator_structure
```

- Focal slots receive overlap and compactness constraints.
- Diffuse maps receive smoothness but no compactness constraint.
- Boundary maps receive local continuity, not direct edge-copy supervision.
- Structural maps receive flip-consistent symmetry-relation constraints.
- Query maps must remain diverse after accounting for route weight.

### Total

```text
L = L_ground
  + w_teacher * L_teacher
  + w_mask * L_mask
  + w_query * L_query
```

Only four top-level weights are exposed. Sub-loss ratios are fixed in the spec implementation and are not swept on MS-CXR.

## Training Schedule

### Phase A: Locality Warm-Up

Train only the feature pyramid and masked predictor on leakage-free MIMIC-CXR images. AFLoc remains frozen.

### Phase B: Sparse Grounding

Enable phrase projector, router, four query operators, dense decoder, `L_ground`, and `L_query`. Initialize the EMA teacher after the student produces non-collapsed maps.

### Phase C: Dual Consistency

Enable `L_teacher`, retain all other losses, and select the checkpoint using held-out annotation-free validation diagnostics.

No phase uses MS-CXR boxes, masks, heatmaps, or metrics.

## Required Anti-Collapse Diagnostics

Training and validation reports must include:

- final heatmap mean, standard deviation, entropy, active-area ratio, and peak count;
- positive-negative phrase margin;
- top-k patch stability across augmentations;
- teacher confident-patch coverage;
- student-teacher heatmap distance;
- route mean, entropy, and per-query utilization;
- query-map pairwise cosine similarity;
- per-query active area and spatial variance;
- masked latent reconstruction error by AFLoc scale;
- gradient norm by neck, router, each query operator, and decoder;
- per-finding diagnostics grouped by report-derived finding mention;
- left/right flip consistency and counterfactual rejection accuracy.

Training must stop with an explicit failed status if all maps become constant, one query captures nearly all samples, confident coverage collapses, or phrase margins vanish.

## Inference

1. Encode one image and one phrase with frozen AFLoc.
2. Build the locality-aligned pyramid.
3. Route the phrase through all four query operators.
4. Decode one direct final heatmap.
5. Return query maps and reliability for analysis.

No disease ID, report context, DCEM output, region map, or gate is required at inference.

## Evaluation Protocol

### Main Comparisons

```text
AFLoc-MRSG vs AFLoc
AFLoc-MRSG vs phrase_anatomy_dcem
AFLoc-MRSG vs dense_dp_msa_b_evidence_calibrated
```

DCEM-v3 is a comparator only. The model is evaluated raw, without a validation gate.

### Metrics

- CNR for continuous evidence concentration;
- IoU and Dice using the existing frozen threshold protocol;
- pointing-game/top-k hit where available;
- macro, pooled, per-class, and phrase-subtype paired bootstrap intervals.

### Required Ablations

| Ablation | Question |
|---|---|
| single AFLoc scale | Does the locality-aligned pyramid matter? |
| sentence only, no word tokens | Does real token grounding matter? |
| one generic query | Do morphology operators matter? |
| no sparse gate | Does query-specific sparsity matter? |
| no teacher consistency | Does box-free teacher supervision matter? |
| no masked patch distillation | Does locality preservation matter? |
| no raw-image edge/contrast channels | Does boundary inductive bias help pneumothorax? |
| uniform route weights | Does semantic routing matter? |

No ablation adds DCEM fusion or a disease-specific gate.

## Success Criteria

The architecture proceeds as the paper main method only if all are satisfied:

1. raw macro CNR versus AFLoc has positive mean with a non-negative or practically non-harmful CI lower bound;
2. macro IoU or Dice improves versus AFLoc;
3. raw performance is competitive with or better than DCEM-v3 on at least two macro localization metrics;
4. Pneumothorax no longer shows statistically significant harm versus AFLoc;
5. at least two of Pneumonia, Consolidation, and Lung Opacity improve on one overlap metric;
6. query and teacher diagnostics show no collapse;
7. gains survive a second localization dataset or a predefined external evaluation protocol.

Failure to beat DCEM-v3 does not permit adding DCEM fusion and relabeling the result as the main method. It triggers failure analysis or an honest ablation conclusion.

## Disease-Level Hypotheses

| Finding | Hypothesis tested by AFLoc-MRSG |
|---|---|
| Pneumothorax | high-resolution boundary continuity and phrase location tokens correct broad-lung misdirection |
| Pleural Effusion | boundary and diffuse evidence jointly represent pleural contour and broad dependent opacity |
| Cardiomegaly | structural symmetry and global shape evidence preserve strong silhouette localization |
| Edema | diffuse relation attention avoids forcing a compact lesion map |
| Atelectasis | focal-set and structural queries separate opacity from volume-loss evidence |
| Consolidation | focal-set slots and hard phrase negatives reduce opacity-class confusion |
| Pneumonia | phrase-token routing selects focal, multifocal, or diffuse behavior per sentence |
| Lung Opacity | word-level evidence avoids treating the broad category as one fixed morphology |

These hypotheses determine analyses and ablations, not branch labels.

## Main Risks and Mitigations

| Risk | Mitigation |
|---|---|
| teacher confirmation bias | confidence intersection across scale, augmentation, route, and phrase margin |
| language shortcut | cross-image negatives, counterfactual phrases, and visual token reconstruction |
| constant-map equivariance | output variance, phrase margins, and cross-image discrimination |
| boundary query learns image frame | geometry augmentation, local continuity, and phrase-specific negatives |
| router collapses to one query | route balance, temperature schedule, and utilization diagnostics |
| handcrafted disease behavior | text descriptions and soft routing; no disease IDs or conditionals |
| MS-CXR leakage through MIMIC | patient/study/DICOM exclusion manifest verified before training |
| excessive component count | three declared innovations, four operators, four top-level loss groups |

## Final Decision

AFLoc-MRSG was evaluated as a standalone box-free grounding candidate intended
to replace DCEM-v3, with DCEM-v3 retained as an external baseline. Held-out
evaluation rejected that replacement. The architecture remains a historical
ablation built around four morphology operators, three proposed innovations,
and four top-level loss groups.
